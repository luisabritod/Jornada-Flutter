# ☁️ 07 - Integração com Backend (Firebase)

Este módulo marca o início da jornada no desenvolvimento de aplicativos full-stack, conectando o front-end em Flutter com serviços de backend na nuvem.

O foco aqui é aprender a usar o **Firebase** para dar superpoderes aos nossos apps, como persistência de dados em tempo real, autenticação e muito mais.

---

## 📂 Projetos Desenvolvidos

### 1. **To-Do App com Cloud Firestore**
Um aplicativo de lista de tarefas completo com operações CRUD (Criar, Ler, Atualizar, Deletar), onde todos os dados são salvos e sincronizados em tempo real com o banco de dados NoSQL do Firebase, o Cloud Firestore.
