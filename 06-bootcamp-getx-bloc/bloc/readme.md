# 🧱 Estudos de BLoC

### 1. **App Contador**
Um projeto fundamental para entender o fluxo de `Eventos -> BLoC -> Estados` e os principais widgets do pacote `flutter_bloc`.

Um app que consome uma API para praticar operações assíncronas e o gerenciamento de múltiplos estados (loading, success, error) de forma explícita e segura com BLoC.

* **[➡️ Ver Detalhes do App Gerador de Conselhos](./conselhos_bloc/README.md)**
